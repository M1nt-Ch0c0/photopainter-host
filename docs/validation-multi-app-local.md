2. 备份后部署新分区表/宿主，验证原 photoframe 的 A/B 和 NVS 导入。

4. 真实掉电中断候选、包写入及切换恢复；无 ID 的原定时 pusher 不误投其他应用。
5. 每次用于确认应用的推图需 HTTP 200 和人工检查内容、方向与颜色。
