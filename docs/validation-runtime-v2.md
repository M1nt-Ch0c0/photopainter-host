## 已完成真机检查

设备识别为 ESP32-S3 rev 0.2、16 MiB Flash、8 MiB PSRAM。先停止自动推图，私下备份原 SD Wi-Fi，再读取完整 16777216 字节 Flash、计算 SHA-256，并用 verify-flash 对设备校验，结果 digest matched。备份内容及密钥均在仓库外，不写入本文。

| 操作 | 自动证据 |
|---|---|
| 新宿主启动旧 ABI 1 photoframe v15 | ready=true；原 photoframe [15,14]、color-test [1,2] 保留 |
| 旧 ABI 1 真实推图 | HTTP 200，随后 runtime_ready/confirmed=true |
| stage 相框 ABI 2 v16 | 202；写入 B，保留 A v15 |
| activate 相框 v16 | 200，约 20.076 秒；无外部 PNG 自主首屏并确认；A/B=[15,16] |
| ABI 2 额度图推送 | 200，约 20.206 秒；缓存 384000 字节 |
| stage 色带 ABI 2 v3 | 202；相框两个版本不变 |
| activate 色带 v3 | 200，约 19.993 秒；无 PNG 自主生成首屏；A/B=[1,3] |
| 缺失/错误令牌 | 各返回 401，无应用执行 |
| 超过 5 MiB 的实际上传 | 发送声明超限的请求及一个体字节后返回 413，无应用执行 |

只有声明 Content-Length 而完全不发送请求体的探针在 HTTP 服务器解析阶段超时为 408；它不代表超限上传已经被应用接纳。

色带启动后：payload_abi=2、runtime_ready=true、confirmed=true、generation=3、cache_bytes=384000；当前空闲 free_psram=7990356，最低 minimum_free_psram=7411080。这是已执行场景的观测值，不是 5 MiB 真机峰值，也不证明长期多次切换无泄漏。
